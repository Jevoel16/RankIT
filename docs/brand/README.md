# RankIT brand assets

The logo is a dark rounded tile with three podium bars (2nd, 1st, 3rd) in the brand gradient
`#2fd0ff` → `#22c98d` and a gold crown over the winner. The master file is
[`frontend-react/public/logo.svg`](../../frontend-react/public/logo.svg); everything else is exported from it.

| File | Use it for |
|---|---|
| `frontend-react/public/logo.svg` | App header, login, display mode, SVG favicon, README |
| `frontend-react/public/favicon.ico` | Browser tab fallback (16, 32, 48 px) |
| `frontend-react/public/apple-touch-icon.png` | iOS home screen (180 px) |
| `frontend-react/public/icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | Web app manifest / Android install |
| `oauth-google-120.png` | Google Cloud → OAuth consent screen → App logo (120×120) |
| `oauth-github-512.png` | GitHub → Settings → Developer settings → OAuth Apps → Upload logo (badge background `#0b1017`) |
| `github-social-preview.png` | GitHub repo → Settings → Social preview (1280×640) |
| `rankit-icon-1024.png` | Anywhere else that wants a large square icon (Vercel, slides, chat avatars) |
| `rankit-mark.svg` | The mark without the tile, for light backgrounds and print |

Next to the mark, the name is set as text "RankIT" in Inter 800, never baked into the icon.
